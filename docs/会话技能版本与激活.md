# 会话技能版本与激活

## 选哪些技能

| 智能体 | 候选来源 |
| --- | --- |
| personal | 当前用户实际安装且启用的技能，每个资源一个版本 |
| expert / orchestrator | Definition 的 Skill bindings，不混入用户安装列表 |
| 专家团 | 每个成员分别使用自己的 Definition bindings |

候选技能只把名称、描述注入原生技能提示词，不提前下载整包。模型选择技能后仍调用原生 `Skill` 工具；完整 SKILL.md 保留原文。默认 agent.md 增加任务匹配时优先使用技能、明确指定技能时先读取说明的指引，不增加强制路由器。

## 安装版本与发布版本

复用原生 SkillRecord。旧记录按版本保留；同一资源最近一次安装/启停的记录代表用户选择，停用后不回退到更早的 enabled 版本。广场发布新版本身不会改变用户安装版本；安装新版才改变新激活的默认选择。已有安装的卡片继续控制实际安装版本。

## 一次激活

```mermaid
flowchart LR
 A[候选技能摘要] --> B[模型调用 Skill]
 B --> C[当前 USE 与角色绑定检查]
 C --> D[原生工具权限允许]
 D --> E[下载指定版本并校验原文]
 E --> F[不可变版本缓存]
 F --> G[保存 Session 激活记录]
 G --> H[原生 Skill 返回完整说明]
```

记录位置：原生 `AgentState.middle_context.egis_agentkit.activated_skills[resource_id]`，由 Session state 存在 PG；不新增表。字段包括 resource_id、resource_version、resource_view_type、source_checksum_sha256、cache_checksum_sha256、cache_dir、skill_name。首次开放说明和文件前即持久化；原生每轮结束继续保存相同 state。

同一个会话首次激活 v1 后，后续轮次继续用 v1；用户后来安装 v2，新会话激活时选 v2，旧会话不自动切换。当前版本没有增加会话内主动换版按钮。

## 恢复与权限

每轮装配从 Session 激活记录恢复确切目录与内容；缓存完整时不重新向 Nacos 下载整包。缓存缺失时只恢复指定版本，校验内容一致；损坏、注册校验值变化则明确报错，不静默换版。

- 每次受保护工具操作重新检查当前 USE、资源停用、个人安装启停；锁版不锁住授权。
- 共享技能保留已激活的审核版本，但必须仍有当前共享授权；撤回共享/撤权即失效。
- Read / Glob / Grep 只额外开放实际已激活版本目录，不开放整个 skills。
- 搜索工具省略目录时，也校验本地 backend 实际缺省 cwd，不允许绕过目录检查。
- 文件写入仍只允许项目工作目录与产物目录；Bash 的权限继续由原生机制控制，这不构成 OS 文件系统沙箱。

升级前已存在、没有 activated_skills 的历史会话，需再次调用 Skill 建立记录；不扫描或放开全部旧缓存目录。用户自定义 agent.md 保留，默认模板和当前本地已有偏好追加技能使用指引。

验证范围：按用户要求未运行测试；本轮仅做静态检查和只读代码审阅。
