# Egis AgentKit 1.0.3 Release Notes

发布日期：2026-11-23。App、Framework、Frontend 版本统一为 **1.0.3**，基于 Python AgentScope **2.0.12**；Mock 开发服务随同一发布标签提交，包版本保持 **0.1.0**。

## 新增与调整

- **定时任务**：新增任务管理、时间规则预览、启停、编辑、试跑、批量删除，以及可筛选、归档和删除的运行记录。支持单次、间隔、每天、每周、隔周、每月、每年规则，按时区计算；任务绑定用户和项目，可选择模型、项目文件和上下文复用。停机恢复仅补最近 24 小时内最后一次应执行项，自动触发使用唯一约束防重复登记。
- **对话中的定时任务工具**：新增 `CreateScheduledTask`、`RunScheduledTask`、`DeleteScheduledTask`，在当前项目操作。用户勾选后才提供给个人助理，执行需逐次确认。无人值守执行采用“不询问”或只读模式，不沿用交互式完全访问权限。
- **原生消息队列**：普通发送和运行中补充统一进入 AgentScope FIFO；支持刷新恢复、编辑、删除、排序及指定本轮引导。队列接口统一校验登录身份、会话归属、项目状态和资源使用权限，前端展示注入、失败和未消费状态。
- **用户消息编辑重发**：提供复制、编辑与重新发送。重发时截断对应会话后续消息和运行状态，并保留项目文件；运行中或队列冲突时明确提示。
- **工作区标签页**：文件、工作区、变更、产物和计划使用统一标签状态，支持多个资源页及会话范围内恢复。预览标签随宽度收窄，鼠标滚轮可左右浏览，不显示横向滚动条。
- **知识库引用**：最终回答完成且正文实际引用后，才在产物下显示“引用来源”。点击打开右侧普通标签页，展示文档名、来源与命中片段；支持多条回答独立引用页，不在新标签页菜单增加入口。
- **专家工作展示**：主对话展示专家开始/结束的工作入口，详情在右上角小窗显示；支持多位专家、缩小、关闭和再次打开。工作状态包含开始/结束时间、工具活动和结果；移除专家展示处理状态，避免已结束仍被前端当作运行中。
- **个人可选工具**：知识库查询从默认装配改为用户勾选装配，调用前检查当前选择和权限。新增互联网搜索占位工具，当前未接入真实搜索服务。
- **外部技能导入**：虚拟用户凭据使用独立的 `/integrations/skills/imports` 接口上传、查询及重试；普通登录用户继续使用管理接口，避免虚拟凭据进入其他管理能力。

## 修复与内部整理

- 修复原生排队执行与专家子会话丢失 HTTP 身份上下文，导致知识库工具提示缺少登录凭据的问题。经鉴权的短期执行凭据存放在私有 MessageBus registry，按用户/Agent/会话及 JWT 有效期校验，删除会话时清理。
- 修复新建任务首条消息提交时依次闪过多个中间页面的问题，保留同一条乐观消息和项目面板状态，失败可重试。
- 修复知识库结果一返回就提前显示引用、未引用片段也计入来源，以及独立引用侧栏自动聚焦产生白框的问题。
- 修复专家邀请权限检查与 `PermissionDecision` 参数不匹配的问题；统一专家运行装配，改善团队工具可用性和运行状态同步。
- 对资源目录、权限、会话列表、身份、项目文件及消息总线清理查询做批量读取和按条件查询，减少重复 SQL，保留写入与调用时的权限复核；补齐当前初始化索引定义。
- 内置原生工具按 SDK 版本登记，避免升级时覆盖不可变工具版本；业务工具保留自己的版本。
- 移除自研引导投递存储/服务，复用原生队列。数据库操作、清理与资源预置统一由部署脚本负责，App CLI 收敛为启动服务、启动文件服务和指定用户管理员授权。
- Mock 知识库改为检索 5 篇本地 Markdown 文档，返回实际相关段落与引用定位，支持范围、条数及阈值筛选；无命中返回空引用。

## 升级要求与边界

部署顺序、SQL 执行命令、校验及回退说明见 [发布与部署](README.md)，精确配置核对见 [nacos.md](nacos.md)。

- 已有 1.0.2 环境执行本版增量 SQL；全新环境使用当前 `scripts/init/pg.sql`，不要在有数据的 schema 重跑首次建表。
- API 和沙箱网关须使用同一份包含 SSE 多页重放修复的 AgentScope 2.0.12 制品，补丁随版本归档。
- cluster 模式的消息队列持久化于 PostgreSQL，standalone 使用内存总线，服务重启后不保留队列。
- 定时任务是无人值守运行，届时无法续签用户登录 JWT；依赖当前用户短期登录凭据的知识库调用仍受该凭据有效性限制，不提供绕过鉴权的服务 Token。
- Mock 文档是开发演示资料；互联网搜索仍为占位实现；本次提交不代表已修改公司 Nacos 或部署公司环境。
