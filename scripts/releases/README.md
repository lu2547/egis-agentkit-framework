# 版本发布脚本

每个发布版本一个目录：`scripts/releases/<版本号>/`。SQL 与人工操作说明一起进入版本控制。

| 发布版本 | 变更与执行入口 |
| --- | --- |
| [1.0.3](1.0.3/README.md) | 定时任务、个人可选工具约束、完整结构核验；队列、专家协作与引用展示更新 |
| [1.0.2](1.0.2/README.md) | SQL 链路优化、3 个新索引及 2 个冗余索引移除；AgentScope 2.0.12 配套 Nacos/镜像说明 |

每次发版需在版本目录中提供：

1. `README.md`：变更范围、适用前提、执行顺序、验证和回退说明。
2. 按 `01_`、`02_` 顺序命名的增量脚本；涉及数据库时注明能否放在事务中、是否可重复执行。
3. `nacos.md`：精确配置路径、新增/修改/删除内容、是否重启；没有配置变更也明确写出。
4. 其他无法脚本化的步骤写在该版说明中，例如镜像构建、平台参数和服务重启。

发布后保留原版本文件；后续修正在新版本目录追加。只执行当前环境尚未应用的版本，并在发布记录中保存目标库/schema、配置 revision、脚本结果和制品版本。首次安装使用 [init](../init/README.md)，增量发布脚本只用于其说明中指定的已有结构。
