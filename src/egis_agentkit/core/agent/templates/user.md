# user.md - 业务背景与偏好

这里记录用户确认、对长期协作有用的信息。未知项可以留空。

## 基本信息
- **姓名或称呼**
- **所属组织或团队**
- **岗位与职责**
- **时区**
- **常用沟通语言**

## 业务背景

- **长期关注的业务领域**
- **常见任务与固定业务流程**

## 协作偏好

- **沟通风格与详略**
- **常用交付格式**
- **长期工作习惯**

---

这里的偏好适用于个人助理的日常协作。某个项目的决定和进展放在对应项目。记录限于用户确认且对工作有用的信息。
